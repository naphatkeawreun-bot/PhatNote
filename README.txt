PhatNote - วิธีเอาขึ้นเว็บด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub (ตั้งเป็น Public)
2. แตกไฟล์ zip แล้วอัปโหลดไฟล์ทั้งหมดขึ้นไปที่หน้าแรกของ repo (ไม่ต้องอยู่ในโฟลเดอร์ย่อย)
3. ไปที่ Settings > Pages > เลือก Branch: main และโฟลเดอร์ / (root) แล้วกด Save
4. รอ 1-2 นาที จะได้ลิงก์รูปแบบ https://ชื่อผู้ใช้.github.io/ชื่อrepo/
5. เปิดลิงก์ใน Safari > ปุ่มแชร์ > เพิ่มไปยังหน้าจอโฮม

หมายเหตุ: ข้อมูลเก็บในเบราว์เซอร์ของเครื่อง ไม่ซิงค์ข้ามเครื่อง
ถ้าแก้ไฟล์แล้วหน้าเว็บไม่เปลี่ยน ให้เปลี่ยนเลข v1 ในไฟล์ sw.js เป็น v2
